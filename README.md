# 口語タミル語の教科書

地域横断型の Standard Spoken Tamil（SST）を、タミル文字・形態・発音・カナの役割を分けて学ぶスマートフォン向け教材です。

## 現在の状態

- `main` の公開正本：`v4.1-rc.1`
- 公開正本の範囲：PART 0＋第1〜20課
- このドラフトPR：`v4.6-preview`
- 追加範囲：補講A〜Hの統合プレビュー
- PR状態：ドラフト・未マージ

旧v2.8の38章を直接復活させず、現行20課にない学習価値だけを再検証して補講へ移しています。旧 `curriculum-v28.js / travel-v28.js / grammar-v28.js` は履歴・移行元であり、正しさの根拠ではありません。

## 言語基準

- 主表示：`primaryRegister:SST`
- 地域プロファイル：`regionalProfile:TN-GENERAL`
- 既定スタイル：`styleTags:[neutral]`
- 内部複合ラベル：`TN-SST`
- 現代チェンナイ：自然さと旅行実用性の照合地点
- 現代文語：`LT-WR` として別の読解層

`TN-SST` は公的規格名ではありません。タミル・ナードゥ州で地域横断的に通じる比較的中立なSSTを、このプロジェクト内で指定する操作的ラベルです。狭義のチェンナイ口語、Madras Bashai、スラング、英語混交を無標の標準にはしません。

## 教材データ

主要例文は次の層を分離します。

1. `targetTamil` — 対象レジスターのタミル文字
2. `orthographicRoman` — 固定表による厳密文字転写
3. `structuredRoman` — 表面形を保つ形態境界付き転写
4. `pronunciationRoman` — 広い学習用発音
5. `katakana` — 発音層から作る音読補助
6. `meaningJa / literalJapanese` — 自然訳／必要時の直訳

表面形にない基底材料は `structuredRoman` へ足さず、必要時だけ `underlyingAnalysis` に置きます。TTSへ渡すのは自然なタミル文字 `ttsText` だけです。

## 本課20課

1. 名詞の形
2. 代名詞と中心格
3. 所有・共同・道具
4. 場所・方向・起点
5. 後置詞＋格
6. 名詞述語・存在・所有・好き
7. 動詞の設計図
8. 一人称の現在・過去・未来
9. 一人称の否定
10. 不定詞
11. 副動詞と動作の連結
12. 進行・完了・準備済みを表す補助動詞
13. 可能・希望・必要・禁止・計画
14. 全人称・数・性・敬意
15. 命令・依頼・勧誘・疑問
16. 名詞句・形容・数・比較
17. 連体修飾
18. 名詞化
19. 引用・発言
20. 条件・理由・目的・時間

PART 0には名詞格・斜格語幹・複数の早見と、12母音×18子音のタップ式文字表があります。

## 補講A〜H

補講は第21〜28課とはせず、本課へ往復する別レイヤーです。

| 補講 | 内容 | 接続する本課 |
|---|---|---|

| B | i-・a-・e- 指示・疑問系列 | 2・15 |
| C | 数・量・人数・時刻・期間 | 1・16 |

| E | 追加・限定・焦点・不定・否定極性 | 2・16・18 |
| F | 完了・経験・準備結果・状態変化 | 11・12・18 |

補講Aは10例、補講B〜Hは各12例です。各補講には、対照表、3つの急所、6解説ブロック、3文の読み取り、5問の診断問題があります。

補講Hの `திறக்கப்பட்டது / எழுதப்பட்டது` は `LT-WR`・`reading-only` として保持し、日常会話の無標生成形にはしません。

## 統合プレビュー

このPRでは `index.html` から `supplement-preview-loader-v46.js` を読み込み、補講A〜H・clarity・別進捗UI・補講ランタイムを一つの境界として順番にロードします。

- 左上メニューから「補講A〜H」を開く
- URLは `#supp=hub` または `#supp=A&view=read` 形式
- 本課保存キー：`tamil-verb-engine-v2`
- 補講保存キー：`tamil-supplements-v42`
- 本課と補講の進捗・採点を相互に混ぜない
- 前提課・復帰課のボタンは第1〜20課だけへ接続
- 補講を第21〜28課とは表示しない

補講画面には「機械検査済み・ネイティブ音声監査待ち」を常時表示します。プレビューローダーの読込に失敗しても、本課20課はそのまま利用できます。

## 音声とスマートフォン

- 例文カード全体をタップ／Enter／Spaceで一回再生
- 全例文の連続再生
- 前／次、停止、通常／低速、1回／2回
- `ta-IN` 音声を優先
- タミル語音声がない場合は短く通知し、既定音声で試行
- 補講は本課と別の音声ドックを使用
- iPhone縦画面では一列表示
- カナは12px以上
- 44〜48px以上のタップ領域
- 下部ナビはsafe areaへ対応

端末TTSはネイティブ音声監査の代替ではありません。

## 起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## 検査

```bash
npm ci
npm test
```

CIは次の層を別ステップで検査します。

- PART 0＋第1〜20課のデータ
- 補講A〜Hの教材構造
- 補講E・F・G・Hの独立言語検査
- 補講専用保存キーとA〜H別進捗
- 統合プレビューのURL・表示・本課往復
- カード全面タップとキーボード操作
- Tamil文字だけのTTS
- 連続再生の文間待機
- TTS API不在時の通知
- iPhone縦画面用CSS、12pxカナ、safe area
- 既存20課のDOM・設定移行・音声挙動

## 公開前に人間が確認する項目

機械検査で確定できないため、次は未承認のままです。

- 発音・韻律・自然な文間休止
- タミル・ナードゥ州内での地域横断的自然さ
- SSTとより局地的・くだけた形の境界
- `-க்கோ / -க்கிட்டேன்` の語用差
- 相互表現の会話頻度と代替形
- 行為者を前面に出さない出来事文の談話差
- `-ப்படு` 受け身の文体範囲
- iPhone実機でのTTS音声選択とスクロール感

これらをネイティブ音声・文体監査で通した後に、補講データの `public` と承認状態を更新します。
