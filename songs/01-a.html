போற போக்குல
pōṟa pōkkula
ポーラ・ポーックラ
「行っている流れの中で」
→ 進んでいく中で／成り行きの中で
= in the course of going / as things move along
単語・形の分解
歌詞の形元の形・分解働き核になる意味
போற pōṟaபோகிற pōgiṟa → 口語縮約動詞・名詞修飾行く／進んでいる〜
போக்குல pōkkulaபோக்கு pōkku + -ல-la名詞＋場所格流れの中で／成り行きの中で

போக்கு pōkku は単なる「移動」ではなく、 進み方・方向・傾向・成り行き・物事の流れまで表せる名詞です。 英語なら course / way / trend / direction の範囲にまたがります。 したがって போற போக்குல pōṟa pōkkula は、単純な “while going” より 「物事が進んでいくその流れの中で」「成り行きのまま進む中で」に近い表現です。

現在地：போ pō「行く」→ 現在系 → 名詞を修飾する口語形போற pōṟa。
போ pō 行く ↓ போகிற... pōgiṟa... 標準寄りの現在系 ↓ போற... pōṟa... 口語現在系 ↓ போற + 名詞 = 「行く〜／行っている〜」
人称・役割標準寄り口語意味
私போகிறேன் pōgiṟēnபோறேன் pōṟēnI go / I'm going
彼போகிறான் pōgiṟānபோறான் pōṟānhe goes / he's going
名詞修飾போகிற pōgiṟaபோற pōṟagoing / that goes

போக்குல pōkkula の末尾 -ல -la は、口語で場所・内部・場面を表す格語尾。標準寄りの -இல் -il に対応します。

வீடு vīḍu + -ல -la → வீட்டுல vīṭṭula
house + LOCATIVE → in / at the house
→ 家に／家で
போக பழகிக்கோ
pōga paḻagikkō
ポーガ・パラギッコー
「行くことに慣れておきな」
→ 進んでいくことに慣れよう
= get used to going / learn to keep moving
単語・形の分解
歌詞の形元の形・分解働き核になる意味
போக pōgaபோ pō + 不定形動詞・不定形行くこと／行くために
பழகிக்கோ paḻagikkōபழகு paḻagu + கொள் koḷ → 口語動詞＋補助動詞慣れておきな／身につけな
現在地：போ pō「行く」の不定形போக pōga + பழகு paḻagu「慣れる」+ கொள் koḷ。
辞書形不定形English日本語
போ pōபோக pōgato go行くこと／行くために
பார் pārபார்க்க pārkkato see見ること／見るために
பேசு pēsuபேச pēsato speak話すこと／話すために
பழகு paḻagu 慣れる ↓ பழகிக் கொள் paḻagik koḷ 自分の状態として身につける ↓ பழகிக்கோ paḻagikkō 慣れておきな／身につけな

கொள் koḷ が補助動詞として後ろにつくと、「自分のために行う」「自分の状態として取り込む」という方向の意味が加わることがあります。英語なら get yourself used to... のような感覚です。

வரும் நாட்கள் பகலென
varum nāṭkaḷ pagalena
ヴァルム・ナートカル・パガレナ
「来る日々は昼のように」
→ これからの日々は明るい昼のように
= the coming days, like daylight
単語・形の分解
歌詞の形元の形・分解働き核になる意味
வரும் varumவா vā → வரும் varum動詞・非過去修飾来る〜／これから来る〜
நாட்கள் nāṭkaḷநாள் nāḷ + -கள் -gaḷ名詞・複数日々
பகலென pagalenaபகல் pagal + என ena名詞＋引用・様態昼のように／昼として
現在地：வா vā「来る」→ 非過去の名詞修飾形 வரும் varum。「これから来る〜」＝「来たる〜」。

வரும் varum は、後ろの நாட்கள் nāṭkaḷ「日々」を修飾しています。英語の the coming days とかなり対応がきれいです。

வா vā 来る
→ வரும் varum coming / that will come
→ வரும் நாட்கள் varum nāṭkaḷ the coming days

பகலென pagalena は பகல் pagal「昼・昼間」+ என ena「〜として／〜のように」。ここでは「昼のように」「明るい昼さながらに」という比喩を作っています。

விடிந்திடும் பாரு
viḍindiḍum pāru
ヴィディンディドゥム・パール
「明けてくるよ、見て」
→ ほら、きっと夜が明ける
= you'll see it dawn / watch, it will brighten
単語・形の分解
歌詞の形元の形・分解働き核になる意味
விடிந்திடும் viḍindiḍumவிடி viḍi「夜が明ける」系動詞・非過去夜が明ける／明るくなる
பாரு pāruபார் pār の口語命令動詞・談話的用法見て／ほら
現在地：விடி viḍi「夜が明ける」→ விடிந்திடும் viḍindiḍum「明けていく／明けるだろう」+ பாரு pāru。

விடிந்திடும் viḍindiḍum は、夜明け・明るくなる変化を表します。ここでの பாரு pāru はタイトルの「〜してみる」と少し違い、文末で「見てな／ほら」という話者の確信を添える感じです。

விடிந்திடும் viḍindiḍum + பாரு pāru
it will dawn + see/watch
→ 「ほら、夜が明けるよ」
மாறும் உலகிலே
māṟum ulagilē
マールム・ウラギレー
「変わる世界の中で」
→ 変わり続ける世界で
= in a changing world
単語・形の分解
歌詞の形元の形・分解働き核になる意味
மாறும் māṟumமாறு māṟu → 非過去修飾動詞・名詞修飾変わる〜
உலகிலே ulagilēஉலகம் ulagam + -இல் -il + -ஏ -ē名詞＋場所格＋強調世界の中で
現在地：மாறு māṟu「変わる」→ 名詞修飾形 மாறும் māṟum + உலகிலே ulagilē「世界で」。

உலகிலே ulagilē は உலகம் ulagam「世界」+ 場所格 -இல் -il + 強調的な -ஏ -ē。ただ「世界で」より「この世界の中でこそ／世界の中で」という少し響きのある形です。

வாழ பழகிக்கோ
vāḻa paḻagikkō
ヴァーラ・パラギッコー
「生きることに慣れておきな」
→ 生きていくことを身につけよう
= get used to living
単語・形の分解
歌詞の形元の形・分解働き核になる意味
வாழ vāḻaவாழ் vāḻ + 不定形動詞・不定形生きること／生きるために
பழகிக்கோ paḻagikkōபழகு paḻagu + கொள் koḷ → 口語動詞＋補助動詞慣れておきな／身につけな
現在地：வாழ் vāḻ「生きる」→ 不定形 வாழ vāḻa + பழகிக்கோ paḻagikkō。

さきほどの போக பழகிக்கோ pōga paḻagikkō と完全に同じ型です。動詞だけを入れ替えれば使えるので、文法として非常に再利用性が高い形です。

型意味
போக பழகிக்கோ pōga paḻagikkō行くことに慣れよう
வாழ பழகிக்கோ vāḻa paḻagikkō生きることに慣れよう
பேச பழகிக்கோ pēsa paḻagikkō話すことに慣れよう
புது பாதை நமக்கென
pudu pādhai namakkena
プドゥ・パーダイ・ナマッケナ
「新しい道は私たちのためのものとして」
→ 私たちには新しい道がある
= a new path meant for us
単語・形の分解
歌詞の形元の形・分解働き核になる意味
புது pudhu語幹そのまま形容詞的語新しい
பாதை pādhai語幹そのまま名詞道／進路／path
நமக்கென namakkenaநமக்கு namakku + என ena代名詞・与格＋様態私たちのために／私たち向けに

பாதை pādhai は物理的な「道」だけでなく、 「進路・方法・これから進む道筋」にも使えます。ここでは人生の新しい選択肢という比喩です。

現在地： 代名詞 நாம் nām「私たち」→ 与格 நமக்கு namakku「私たちに／私たちのために」→ நமக்கென namakkena。
形English日本語
நாம் nāmwe私たちは
நமக்கு namakkuto us / for us私たちに／私たちのために
நமக்கென namakkenafor us / meant for us私たちのためのものとして

英語では for us のように前置詞を前へ置きますが、Tamil では「us」に相当する語へ格語尾を後ろから付けます。したがって நமக்கு namakku は一語で to/for us の役割を持ちます。

இருக்குது நூறு
irukkudhu nūṟu
イルックドゥ・ヌール
「百ある」
→ いくらでもある／道はたくさんある
= there are a hundred / there are plenty
単語・形の分解
歌詞の形元の形・分解働き核になる意味
இருக்குது irukkudhuஇரு iru → 口語中性形動詞・存在ある／いる
நூறு nūṟu数詞数詞百 → たくさん
現在地：இரு iru「いる／ある」→ 口語の非人称・中性形 இருக்குது irukkudhu。

இருக்குது irukkudhu は日常口語で非常によく出る「ある／いる」。標準寄りなら இருக்கிறது irukkiṟadhu。ここでは前行の「新しい道」を受けて、「百もある」＝「たくさんある」と誇張的に言っています。

標準寄り口語意味
