C｜花と棘、時間と傷

பூக்கள் பூக்கும் வழியிலே
pūkkaḷ pūkkum vaḻiyilē
プーッカル・プーックム・ヴァリイレー
「花々が咲く道で」
→ 花が咲く道では
= on the path where flowers bloom
単語・形の分解
歌詞の形元の形・分解働き核になる意味
பூக்கள் pūkkaḷபூ pū「花」+ -க்கள் -kkaḷ名詞・複数花々
பூக்கும் pūkkumபூ pū「咲く」→ 非過去修飾動詞・名詞修飾咲く〜
வழியிலே vaḻiyilēவழி vaḻi + -இல் -il + -ஏ -ē名詞＋場所格＋強調道で／道の中で
現在地：பூ pū「咲く」→ பூக்கும் pūkkum「咲く〜」という名詞修飾形。後ろの வழி vaḻi「道」を説明しています。

English なら the path where flowers bloom と関係詞 where を使いますが、Tamil では பூக்கும் pūkkum をそのまま名詞の前に置けます。

பூக்கள் pūkkaḷ flowers
பூக்கும் pūkkum bloom / that bloom
வழியிலே vaḻiyilē on the path
→ 「花が咲く道で」
முள்ளும் அழகாய் தோன்றிடும்
muḷḷum aḻagāy tōnṟiḍum
ムッルム・アラガーイ・トーンドリドゥム
「棘も美しく見えるだろう」
→ 棘さえ美しく見えてくる
= even thorns will appear beautiful
単語・形の分解
歌詞の形元の形・分解働き核になる意味
முள்ளும் muḷḷumமுள் muḷ + -உம் -um名詞＋添加棘も／棘さえ
அழகாய் aḻagāyஅழகு aḻagu + -ஆய் -āy様態美しく／美しいものとして
தோன்றிடும் tōnṟiḍumதோன்று tōnṟu「現れる／見える」系動詞・非過去見えてくる／現れるだろう
現在地：முள் muḷ「棘」+ -உம் -um「〜も／〜さえ」→ முள்ளும் muḷḷum。

-உம் -um は非常に重要で、文脈により「〜も」「〜さえ」「〜でも」に広がります。英語の also / even / too に対応することがあります。

அழகாய் aḻagāy は அழகு aḻagu「美しさ／美しい」から作られた「美しく」という様態表現。-ஆய் -āy は「〜として／〜のように／〜な状態で」の働きをします。

அழகு aḻagu beauty
→ அழகாய் aḻagāy beautifully / as beautiful
→ அழகாய் தோன்றிடும் aḻagāy tōnṟiḍum will appear beautiful
எதையும் தாங்கும் மனதிலே
edhaiyum tāṅgum manadhilē
エダイユム・ターングム・マナディレー
「何であっても耐える心の中では」
→ 何でも受け止められる心なら
= in a heart that can bear anything
単語・形の分解
歌詞の形元の形・分解働き核になる意味
எதையும் edhaiyumஎது edhu → எதை edhai + -உம் -um代名詞・目的格＋添加何でも／何であっても
தாங்கும் tāṅgumதாங்கு tāṅgu → 非過去修飾動詞・名詞修飾耐える／支える〜
மனதிலே manadhilēமனம் manam + -இல் -il + -ஏ -ē名詞＋場所格＋強調心の中で
現在地：எது edhu「何」→ 目的格 எதை edhai「何を」+ -உம் -um → எதையும் edhaiyum「何であっても／何でも」。
形English日本語
எது edhuwhat何
எதை edhaiwhat (object)何を
எதையும் edhaiyumanything / whatever何でも／何であっても

தாங்கும் tāṅgum は தாங்கு tāṅgu「耐える／支える」の名詞修飾形で、மனம் manam「心」を説明しています。「何でも耐える心」＝ a heart that bears anything。

எதுவும் அதுவாய் நீங்கிடும்
edhuvum adhuvāy nīṅgiḍum
エドゥヴム・アドゥヴァーイ・ニーンギドゥム
「何であっても、そのまま離れていく」
→ どんなことも、やがて過ぎ去っていく
= anything will eventually pass away
単語・形の分解
歌詞の形元の形・分解働き核になる意味
எதுவும் edhuvumஎது edhu + -உம் -um代名詞＋添加何でも／どんなことも
அதுவாய் adhuvāyஅது adhu + -ஆய் -āy指示語＋様態それとして／そのまま
நீங்கிடும் nīṅgiḍumநீங்கு nīṅgu「離れる／去る」系動詞・非過去去っていく／消えていく
現在地：எது edhu + -உம் -um → எதுவும் edhuvum「何であっても／何もかも」。நீங்கு nīṅgu は「離れる・消える・去る」。

அதுவாய் adhuvāy は直訳すると「それとして／その状態で」。歌詞としては「それもまたそのまま過ぎ去っていく」という抽象的な言い方です。自然な日本語では「どんなことも、やがて過ぎ去る」とまとめるのが分かりやすいです。

காலம் ஓடும்
kālam ōḍum
カーラム・オードゥム
「時間は走る」
→ 時は流れていく
= time will run / time passes
単語・形の分解
歌詞の形元の形・分解働き核になる意味
காலம் kālam語幹そのまま名詞時間／時
ஓடும் ōḍumஓடு ōḍu → 非過去動詞走る／流れていく
現在地：ஓடு ōḍu「走る」→ ஓடும் ōḍum「走る／流れていく」。

காலம் kālam は「時間・時」。Tamil でも「時間が走る」という比喩が成立し、日本語の「時は流れる」、英語の time flies / time runs on と似た発想です。

காயம் ஆறும்
kāyam āṟum
カーヤム・アールム
「傷は治る」
→ 傷はやがて癒える
= wounds will heal
単語・形の分解
歌詞の形元の形・分解働き核になる意味
காயம் kāyam語幹そのまま名詞傷／けが
ஆறும் āṟumஆறு āṟu「治る／鎮まる」→ 非過去動詞治る／癒える

ஆறு āṟu には「（傷や痛みが）治る・鎮まる」という意味があります。 名詞の ஆறு āṟu「川」と同じ綴りですが、ここでは別の語義です。

現在地：ஆறு āṟu「治る／鎮まる」→ ஆறும் āṟum「治るだろう／癒えていく」。

காயம் kāyam は身体の「傷」だけでなく、文脈次第で心の傷にも使えます。前の காலம் ஓடும் kālam ōḍum と対になり、「時間が進めば傷も癒える」という構造になっています。

துணை இருக்கு துயர் எதற்கு
thuṇai irukku thuyar edhaṟku
トゥナイ・イルック・トゥヤル・エダルク
「支えがある、悲しみは何のために」
→ 支えがあるのに、なぜ悲しむの
= there is support; what is sorrow for? / why grieve?
単語・形の分解
歌詞の形元の形・分解働き核になる意味
துணை thuṇai語幹そのまま名詞支え／助け／伴う人
இருக்கு irukkuஇரு iru → 口語現在動詞・存在ある／いる
துயர் thuyar語幹そのまま名詞悲しみ／苦しみ
எதற்கு edhaṟkuஎது edhu + -க்கு -kku の変化形疑問代名詞＋与格何のために → なぜ

துணை thuṇai は「助け」だけでなく、 そばにいて支える人・伴侶・支援そのものまで含められる語です。 துயர் thuyar は日常の軽い “sad” よりやや重く、 「悲しみ・苦しみ・嘆き」に近い語です。

現在地：இரு iru「いる／ある」→ 口語 இருக்கு irukku。「ある」。

துணை thuṇai は「支え・連れ・助けとなる存在」。துயர் thuyar は「悲しみ・苦しみ」。எதற்கு edhaṟku は எது edhu「何」+ 与格 -க்கு -kku で、「何のために？」→ 文脈では「なぜ？」です。

形構造意味
எது edhuwhat何
எதற்கு edhaṟkuwhat + to/for何のために → なぜ
