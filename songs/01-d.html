D｜昨日・明日・今日

நேற்று நிழலாய் போனது
nēṟṟu niḻalāy pōnadhu
ネートル・ニララーイ・ポーナドゥ
「昨日は影のように去った」
→ 昨日は影のように過ぎ去った
= yesterday went away like a shadow
単語・形の分解
歌詞の形元の形・分解働き核になる意味
நேற்று nēṟṟu語幹そのまま時間副詞昨日
நிழலாய் niḻalāyநிழல் niḻal + -ஆய் -āy名詞＋様態影のように／影となって
போனது pōnadhuபோ pō → 過去中性動詞・過去行った／去った
現在地：போ pō「行く」→ 過去・中性形 போனது pōnadhu「行った／去った」。

நேற்று nēṟṟu は「昨日」。நிழல் niḻal「影」+ -ஆய் -āy → நிழலாய் niḻalāy「影のように／影となって」。

நிழல் niḻal shadow
→ நிழலாய் niḻalāy as a shadow / like a shadow
நாளை கணவாய் நீளுது
nāḷai kaṇavāy nīḷudhu
ナーライ・カナヴァーイ・ニールドゥ
「明日は夢のように伸びていく」
→ 明日は夢のように広がっていく
= tomorrow stretches out like a dream
単語・形の分解
歌詞の形元の形・分解働き核になる意味
நாளை nāḷai語幹そのまま時間副詞明日
கணவாய் kaṇavāy提供歌詞の形。文脈上 கனவாய் kanavāy「夢のように」の可能性が高い様態夢のように（文脈解釈）
நீளுது nīḷudhuநீள் nīḷ → 口語中性動詞・現在伸びる／広がっていく
綴りメモ： 提供歌詞は கணவாய் kaṇavāy ですが、文脈上は கனவாய் kanavāy「夢のように／夢として」と読む可能性が高いです。ここでは意味は「夢として」で取ります。
現在地：நீள் nīḷ「長くなる／伸びる」→ 口語中性形 நீளுது nīḷudhu「伸びている／広がっていく」。

நாளை nāḷai は「明日」。前行が過去の போனது pōnadhu なのに対し、ここでは未来側が「伸びていく」ものとして描かれています。

இன்று நிஜமாய் ஆனது
inṟu nijamāy ānadhu
インル・ニジャマーイ・アーナドゥ
「今日は現実になった」
→ 今日こそ現実になった
= today became real
単語・形の分解
歌詞の形元の形・分解働き核になる意味
இன்று inṟu語幹そのまま時間副詞今日
நிஜமாய் nijamāyநிஜம் nijam + -ஆய் -āy名詞＋様態現実として／本当に
ஆனது ānadhuஆகு āgu → 過去中性動詞・過去なった
現在地：ஆகு āgu「なる」→ 過去・中性形 ஆனது ānadhu「なった」。

நிஜம் nijam は「現実・本当」。நிஜமாய் nijamāy で「現実として／現実になって」。

時間歌詞の動き意味
நேற்று nēṟṟuபோனது pōnadhu昨日は去った
நாளை nāḷaiநீளுது nīḷudhu明日は伸びていく
இன்று inṟuஆனது ānadhu今日は現実になった
இது தன வாழ்க்கை என்பது
idhu thana vāḻkkai enbadhu
イドゥ・タナ・ヴァールッカイ・エンバドゥ
「これこそが人生というもの」
→ これが人生というものなんだ
= this is what life is
単語・形の分解
歌詞の形元の形・分解働き核になる意味
இது idhu指示代名詞代名詞これ
தன thana提供歌詞の形。文脈上 தான் thān の可能性あり強調候補〜こそ／まさに
வாழ்க்கை vāḻkkai語幹そのまま名詞人生／生活
என்பது enbadhuஎன் en「と言う」系から作る名詞化名詞化〜ということ／〜というもの
綴りメモ： 文脈上は இது தான் வாழ்க்கை என்பது idhu thān vāḻkkai enbadhu「これこそが人生というもの」と解釈するのが自然です。提供歌詞の தன thana は、歌唱・転記上の省略または表記揺れの可能性があります。

தான் thān は強調の助詞で、「まさに〜」「〜こそ」「〜なんだ」に近い働き。என்பது enbadhu は「〜ということ／〜というもの」を作ります。

இது idhu this
+ தான் thān exactly / indeed
+ வாழ்க்கை vāḻkkai life
+ என்பது enbadhu what is called / the fact that
→ 「これこそが人生というもの」
ஓடம் ஒரு நாள்
ōḍam oru nāḷ
オーダム・オル・ナール
「舟は、ある日」
→ 舟もいつか
= a boat, one day
単語・形の分解
歌詞の形元の形・分解働き核になる意味
ஓடம் ōḍam語幹そのまま名詞舟／船
ஒரு oru数詞・不定数詞一つの／ある
நாள் nāḷ語幹そのまま名詞日

ஓடம் ōḍam は「舟・船」。ஒரு நாள் oru nāḷ は直訳「ある一日」ですが、物語的には「いつか／one day」。

சேரும் கரையே
sērum karaiyē
セールム・カライイェー
「たどり着く、その岸へ」
→ いつか岸へたどり着く
= will reach the shore
単語・形の分解
歌詞の形元の形・分解働き核になる意味
சேரும் sērumசேர் sēr → 非過去動詞着く／たどり着くだろう
கரையே karaiyēகரை karai + -ஏ -ē名詞＋強調岸へ／その岸こそ
現在地：சேர் sēr「到達する／合流する」→ சேரும் sērum「到達するだろう／たどり着く」。

கரை karai は「岸」。語尾 -ஏ -ē が強調を加え、கரையே karaiyē は「その岸へ／岸こそ」と響きを強めています。

ஓடம் ōḍam boat
+ ஒரு நாள் oru nāḷ one day
+ சேரும் sērum will reach
+ கரையே karaiyē the shore
→ 「舟もいつか岸へたどり着く」
துணை இருக்கு துயர் எதற்கு
thuṇai irukku thuyar edhaṟku
トゥナイ・イルック・トゥヤル・エダルク
「支えがある、悲しみは何のために」
→ 支えがあるのに、なぜ悲しむの
= there is support; why grieve?
単語・形の分解
歌詞の形元の形・分解働き核になる意味
துணை thuṇai語幹そのまま名詞支え／助け／伴う人
இருக்கு irukkuஇரு iru → 口語現在動詞・存在ある／いる
துயர் thuyar語幹そのまま名詞悲しみ／苦しみ
எதற்கு edhaṟkuஎது edhu + -க்கு -kku の変化形疑問代名詞＋与格何のために → なぜ

துணை thuṇai は「助け」だけでなく、 そばにいて支える人・伴侶・支援そのものまで含められる語です。 துயர் thuyar は日常の軽い “sad” よりやや重く、 「悲しみ・苦しみ・嘆き」に近い語です。

வாழ்ந்து பாரு
vāḻndhu pāru
ヴァーランドゥ・パール
「生きて、見てみて」
→ 生きてみよう
= try living
単語・形の分解
歌詞の形元の形・分解働き核になる意味
வாழ்ந்து vāḻndhuவாழ் vāḻ → 連結形動詞・連結形生きて
பாரு pāruபார் pār → 口語命令／補助動詞動詞見て → 〜してみて
