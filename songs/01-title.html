曲名｜வாழ்ந்து பாரு vāḻndhu pāru

現在地：வாழ் vāḻ「生きる」→ 連結形 வாழ்ந்து vāḻndhu → 補助動詞的な பாரு pāru。
形元の形役割意味
வாழ்ந்து vāḻndhuவாழ் vāḻ連結形生きて
பாரு pāruபார் pār口語命令／補助動詞見て → 〜してみて

வாழ் vāḻ は「生きる／暮らす」。次の動詞へつなぐと வாழ்ந்து vāḻndhu「生きて」になります。Tamil では、動詞をいったんこの種の連結形にして、後ろへ別の動詞を重ねることが非常に多いです。

வாழ்ந்து பாரு vāḻndhu pāru
live + linking form + see/try
→ try living
→ 「生きてみる」

பார் pār は「見る」ですが、他の動詞の後ろでは「実際にやってみる」という試行の意味を作れます。英語の try + -ing と対応させると構造が見えやすいです。

文を読むための四つの足場

歌詞へ入る前の足場です。先の課で見た形を、今回の曲に必要な理由から捉え直します。

1．まず「誰が・何を・どうする」を探す

日本語と同じく、タミル語の基本的な語順は主語―目的語―動詞です。ただし主語は省略でき、格が役割を示すため順序も動きます。歌の一行が一文とは限りません。改行で切らず、文を終えられる述語を探してから、その述語の相手を拾います。

நான் தமிழ் படிக்கிறேன். nān thamiḻ paḍikkiṟēn
私はタミル語を勉強します。

நான் が主語、தமிழ் が学ぶ対象、படிக்கிறேன் が述語。最後の -ēn が一人称単数を示すので、文脈があれば「私」を省いても伝わります。目的語にいつでも -ai が見えるとは限りません。

2．動詞は、次に何を置けるかで分ける

同じ動作でも、文を終える形・別の動詞へつなぐ形・名詞を説明する形を使い分けます。日本語訳の「〜る」だけでは判別できません。歌詞を読むときは、右隣にある語の種類を見るのが近道です。

வருகிறேன் / வர / வந்து / வரும் பறவை varugiṟēn / vara / vandhu / varum paṟavai
来ます／来ることを別の述語につなぐ形／来て／やって来る鳥

varugiṟēn は人称を持つ述語。vara は不定形で、目的・助動詞などとの組合せに使います。vandhu は連結形で次の動作へつなぎます。varum はここでは鳥を説明する名詞修飾形です。-um を見ただけで「未来の文」と決めないこと。

3．格を付ける前に、名詞の土台が変わることがある

格とは「誰に」「どこで」などの関係を示す印です。辞書に出る形へ単純に継ぎ足すだけとは限りません。変化した土台を斜格語幹と呼びます。最初はよく使うまとまりごと覚え、それから共通部分を見つけましょう。

வீடு → வீட்டில் / மரம் → மரத்தில் / நான் → எனக்கு vīḍu → vīṭṭil / maram → maratthil / nān → enakku
家→家で／木→木で・木に／私→私に

vīḍu は vīṭṭ-、maram は maratth- になって -il を受けます。nān→enakku は代名詞独自の形です。人を目的語にする場面では -ai が重要になり、物では特定性などにも左右されます。「口語では全部落とす」という規則にはしません。

4．文字と音を一対一のカナにしない

母音の長短と子音の長さは、意味を区別する材料です。ā は長い a、二重子音は一つより長く保ちます。ḷ・ḻ・l や ṟ・r の区別はカナだけでは表せません。文字、ローマ字、利用できる音声を並べて確認してください。

கல் / கால் kal / kāl
石／脚・足

同じように見えても母音の長さで別語です。本教材のカナは入口で、発音の保証ではありません。歌唱では音が伸びたり語が分かれたりするため、歌の長さをそのまま辞書の長母音と判断しません。
