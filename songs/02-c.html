F｜条件「〜なら」・比喩・使役

நீ விட்டு போனால்
nī viṭṭu pōnāl
ニー・ヴィットゥ・ポーナール
「君が置いて行ってしまうなら」
→ 君が僕を置いて去ったら
= if you leave and go
単語・形の分解
歌詞の形元の形・分解働き意味
நீ nī2人称単数代名詞君
விட்டு viṭṭuவிடு viḍu「離す／置く」系連結形置いて／離れて
போனால் pōnālபோ pō + 条件 -னால் -nāl条件行ったら／去ったら
現在地： -னால் -nāl = 「〜したら／もし〜なら」。会話でも非常に使える条件形です。
போ pō → போனால் pōnāl
go → if [someone] goes
→ 「行ったら／去ったら」
மனம் குரங்காய் உன்னை நாடும்
manam kuraṅgāy unnai nāḍum
マナム・クランガーイ・ウンナイ・ナードゥム
「心は猿のようになって、君を探し求める」
→ 心は落ち着かず、君を必死に探す
= the heart, like a monkey, will seek you
மனம் manam標準寄りの「心」名詞心
குரங்காய் kuraṅgāyகுரங்கு kuraṅgu + -ஆய் -āy比喩・様態猿のように／猿となって
உன்னை unnaiநீ nī の目的格代名詞・目的格君を
நாடும் nāḍumநாடு nāḍu「求める／探し求める」→ 非過去動詞求める／探す

குரங்கு kuraṅgu「猿」は、落ち着かず動き回るものの比喩。குரங்காய் kuraṅgāy は Lesson 1 の அழகாய் aḻagāy、この曲の வரமாய் varamāy と同じ -ஆய் -āy です。

நீ மாறச்சொன்னாள்
nī māṟac connāḷ
ニー・マーラチ・ソンナール
「君が変われと言ったら／言うなら」
→ 君が『変わって』と言うなら
= if you tell me to change
歌詞表記の注意： 提供歌詞は மாறச்சொன்னாள் māṟac connāḷ。文脈上は「君が変われと言うなら」という条件なので、意味としては மாறச் சொன்னால் māṟac connāl と読むのが自然です。教材では提供された綴りを残しつつ、条件の意味で扱います。
மாற māṟaமாறு māṟu + 不定形動詞変わること／変わるように
சொன்னால் connālசொல் sol「言う」+ 過去条件条件言ったら／言うなら
தீ வால் கொண்டு காடு எரியும்
thī vāl koṇḍu kāḍu eriyum
ティー・ヴァール・コンドゥ・カードゥ・エリユム
「火の尾を使って、森は燃える」
→ 火のついた尻尾で森じゅう燃やしてしまう
= with a fiery tail, the forest will burn
தீ thī語幹そのまま名詞火
வால் vāl語幹そのまま名詞尾／しっぽ
கொண்டு koṇḍuகொள் koḷ 系手段・連結〜を使って／〜を持って
காடு kāḍu語幹そのまま名詞森
எரியும் eriyumஎரி eri「燃える」→ 非過去動詞燃える／燃えるだろう

கொண்டு koṇḍu は「持って」から広がって、道具・手段の「〜を使って／with」によく使われます。英語の with、日本語の「〜で」に近い役割を持つことがあります。

நெஞ்ச தைக்கிற ஏன்டி கெஞ்ச வைக்கிற
nenja thaikkiṟa ēṇḍi kenja vaikkiṟa
ネンジャ・タイッキラ・エーンディ・ケンジャ・ヴァイッキラ
「胸を刺す、なんでだよ君、懇願させる」
→ 胸をえぐって、なんで僕にこんなに懇願させるんだよ
= you pierce my heart; why do you make me beg?
நெஞ்ச nenja口語で目的格が縮んだ நெஞ்சை nenjai 系名詞・目的語胸を／心を
தைக்கிற thaikkiṟaதை thai「縫う／刺す」系 + 口語現在動詞刺す／縫い刺す
ஏன்டி ēṇḍiஏன் ēn「なぜ」+ 女性への親しい呼びかけ டி ḍi口語間投なんでだよ／なんでなの、君
கெஞ்ச kenjaகெஞ்சு kenju「懇願する」+ 不定形動詞頼み込む／懇願する
வைக்கிற vaikkiṟaவை vai「置く」→ 使役的補助動詞使役〜させる
現在地： V + வை vai で「Vさせる」。ここでは கெஞ்ச வைக்கிற kenja vaikkiṟa = 「懇願させる」。
கெஞ்ச kenja + வைக்கிற vaikkiṟa
beg + make
→ make [someone] beg
→ 「懇願させる」
