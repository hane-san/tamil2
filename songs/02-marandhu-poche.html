Lesson 2

மறந்து போச்சே

maṟandhu pōccē
マランドゥ・ポーチェー
「忘れて、行ってしまった」
→ 忘れちゃった／すっかり忘れた
= having forgotten, it has gone / ended up forgotten
青いタミル語をタップすると読み上げます。
歌：Adithya RK · 音楽：Sean Roldan · 作詞：Madhan

この曲で先に掴む形

① போச்சுpōccu — 「行った」から広がる、結果・完了・「〜しちゃった」
② புரியலpuriyala — 「分からない」の口語否定
③ தெரியலtheriyala — 「知らない／分からない」の口語否定
④ பக்கத்துலpakkathula — 「そばで／隣に」＋口語場所格 -ல

曲名｜மறந்து போச்சேmaṟandhu pōccē

現在地： மறmaṟa「忘れる」系 → 連結形 மறந்துmaṟandhu + 結果を表す口語 போச்சேpōccē。
形元の形・分解働き核になる意味
மறந்துmaṟandhuமறmaṟa「忘れる」系連結形忘れて
போச்சேpōccēபோச்சுpōccu + 強調的な -ē口語・結果行ってしまった → 〜しちゃった

போpō は基本的には「行く」。ところが、別の状態変化のあとに置かれると、物理的な「行く」よりもその変化が完了して、元へ戻らない感じを強く出します。

மறந்துmaṟandhu + போச்சுpōccu
forgot / having forgotten + went off / ended up
→ 「忘れちゃった」「すっかり忘れた」

日本語の「〜しちゃった」、英語の ended up ... / has gone and ... に近い結果感を持つことがあります。Lesson 1 の単純な போpō「行く」から、意味がかなり広がるところがこの曲の大事なポイントです。

போச்சுpōccu｜結果が出てしまった

現在地： 「移動」ではなく、出来事の結果・完了として使う口語。

போச்சுpōccu は会話で非常によく聞こえる形です。単純に「行った」と訳すより、前の動作や状態と組み合わさったときは「〜になっちゃった」「〜してしまった」と取るほうが自然な場合があります。

見る場所English日本語
போpōgo行く
போச்சுpōccuwent / is gone / ended up行っちゃった／〜になっちゃった
போச்சேpōccēit's really gone / look, it ended up...〜しちゃったよ／ほんとに〜になった

口語否定｜புரியலpuriyala・தெரியலtheriyala

現在地： 標準寄りの否定が、会話で短くなった形。
標準寄り口語English日本語
புரியவில்லைpuriyavillaiபுரியலpuriyalaI don't understand / it isn't clear分からない
தெரியவில்லைtheriyavillaiதெரியலtheriyalaI don't know知らない／分からない
புரியவில்லை puriyavillai ↓ 口語で大きく縮む புரியல puriyala தெரியவில்லை theriyavillai ↓ தெரியல theriyala

歌だけでなく、日常会話を聞くうえでも非常に重要です。教科書の -villai だけを覚えていると、実際の -la が別の語に聞こえやすいため、最初から両方を対応させて覚えます。

場所格｜பக்கத்துலpakkathula

現在地： பக்கம்pakkam「側・そば」+ 口語場所格 -ல -la。
形分解English日本語
பக்கம்pakkam名詞side / vicinity側／近く
பக்கத்துலpakkathulaபக்கத்துpakkathu + -லbeside / nearby / next toそばに／隣で

Lesson 1 の போக்குலpōkkula と同じ -ல -la がここでも出ます。違う単語で同じ格語尾にもう一度出会うことで、「-la = in / at / on / near のような場所関係」という感覚を固めます。
