曲名｜மறந்து போச்சே maṟandhu pōccē

現在地： மற maṟa「忘れる」系 → 連結形 மறந்து maṟandhu + 結果・完了を表す口語 போச்சே pōccē。
形元の形・分解働き核になる意味
மறந்து maṟandhuமற maṟa「忘れる」系連結形忘れて
போச்சே pōccēபோச்சு pōccu + 強調的な -ē口語・結果行ってしまった → 〜しちゃった
மறந்து maṟandhu + போச்சு pōccu
having forgotten + went off / ended up
→ 「忘れちゃった」「すっかり忘れた」

போ pō は基本的には「行く」ですが、別の動作・状態変化の後ろに来ると、物理的な移動よりも「その状態になってしまった」「結果がもう出た」という完了感を強めることがあります。Lesson 1 の単純な「行く」から、一段意味が広がるところです。

否定と「結果」を別々に読む

歌詞へ入る前の足場です。先の課で見た形を、今回の曲に必要な理由から捉え直します。

1．「ない」は一種類ではない

第1課では肯定文の述語を探しました。今度は何を否定しているかを先に決めます。名詞として同じ物ではないのか、物が存在しないのか、ある動作をしなかったのかで形が変わります。

இது புத்தகம் இல்லை. / புத்தகம் இல்லை. / நான் வரவில்லை. idhu putthagam illai / putthagam illai / nān varavillai
これは本ではない／本がない／私は来なかった

最初は名詞述語の否定、次は存在の否定、最後は動詞の否定。varavillai は文脈により非過去の否定にも使われ、口語 varala と機械的に一つの時制だけで結びません。歌の puriyala「分からない」は状態の否定です。

2．pōccu は単なる過去印ではない

「忘れた」と「忘れてしまった」の違いを考えます。連結形に続く pōccu は、変化が起きてその結果になったことを際立たせます。残念さは文脈から出ることが多く、どんな動詞にも必ず後悔を足す語ではありません。

மறந்தேன் / மறந்து போச்சு maṟandhēn / maṟandhu pōccu
私は忘れた／忘れてしまった・すっかり忘れた

前者は -ēn から一人称が分かります。後者の pōccu は中性の形で、そのまま「私」の人称語尾には分解しません。誰の経験かは周辺の文から補います。時制は出来事の位置、結果・完了は出来事をどう眺めるか、という別の軸です。

3．疑問詞の質問と、はい・いいえの質問

文末を上げるだけでなく、-ā が質問の印になります。一方「何」「どこ」などの疑問詞がある文は、それ自体で答えるべき空欄を作ります。何でも末尾に -ā を加える必要はありません。

இது புத்தகமா? / இது என்ன? / நீ வருவாயா? idhu putthagamā / idhu enna / nī varuvāyā
これは本？／これは何？／君は来る？

putthagam+ā では名詞を問い、varuvāy+ā では動詞の述語を問います。疑問の -ā と条件の -ā は、形だけでなく「返答を求める文か、後半の条件を置く節か」で区別します。
