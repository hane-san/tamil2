இன்னும் எத்தனை காலம்
innum ettanai kālam
イッヌム・エッタナイ・カーラム
「まだ、どれほどの時間」
→ あとどれくらい？／いつまで？
= how much longer? / for how long still?
単語・形の分解
歌詞の形元の形・分解働き核になる意味
இன்னும் innum語幹そのまま副詞まだ／さらに／もう少し
எத்தனை ettanai疑問数量語数量を尋ねるいくつ／どれほど
காலம் kālam語幹そのまま名詞時間／期間／時

இன்னும் innum はかなり重要です。「まだ」だけでなく、「さらに」「もう少し」「これ以上」の方向へも広がります。後ろに疑問語が来ると、“how much more / how much longer” の感覚を作れます。

TamilEnglish日本語
இன்னும் கொஞ்சம் innum konjama little moreもう少し
இன்னும் நேரம் இருக்கு innum nēram irukkuthere is still timeまだ時間がある
இன்னும் எத்தனை நாள்? innum ettanai nāḷ?how many more days?あと何日？
இன்னும் எத்தனை காலம்? innum ettanai kālam?how much longer?あとどれくらい？／いつまで？

எத்தனை ettanai は「数」を尋ねる語です。என்ன enna「何」とは役割が違い、後ろに数えられる名詞や期間の名詞が来ます。

எத்தனை பேர்? ettanai pēr? = how many people? → 何人？
எத்தனை நாள்? ettanai nāḷ? = how many days? → 何日？
எத்தனை காலம்? ettanai kālam? = how long? → どれくらいの間？

காலம் kālam は Lesson 1 の காலம் ஓடும் kālam ōḍum「時は流れる」にも出た語です。今回は「時間という概念」より、どれくらい続く期間かという意味で使われています。

人・時間・引用をつなぐ

歌詞へ入る前の足場です。先の課で見た形を、今回の曲に必要な理由から捉え直します。

1．近い・遠い・尋ねるをひと組で覚える

指示語は物の名前を知らなくても文を作れる道具です。単独で「これ」と言う形と、名詞の前で「この」と言う形を区別しましょう。

இது / அது / எது; இந்த புத்தகம் / அந்த புத்தகம் / எந்த புத்தகம் idhu / adhu / edhu; indha putthagam / andha putthagam / endha putthagam
これ／それ・あれ／どれ；この本／その本／どの本

idhu をそのまま「この」の位置へ置くのではなく、名詞を修飾する indha を選びます。場所は iṅgē/aṅgē/eṅgē「ここ／そこ／どこ」、様子は ippadi/appadi/eppadi「こう／そう／どう」と、似た系列で整理できます。

2．時制と人称は別の質問に答える

未来形の -vēn/-ppēn を丸暗記するだけでなく、「何の動作」「いつ・どんな見通し」「誰」の三つを見ます。動詞によって接続する形が違うため、全動詞に v を足す規則は作りません。

வந்தேன் / வருகிறேன் / வருவேன்; படித்தேன் / படிக்கிறேன் / படிப்பேன் vandhēn / varugiṟēn / varuvēn; paḍitthēn / paḍikkiṟēn / paḍippēn
来た／来る・来ている／来るつもり；勉強した／勉強する／勉強するつもり

どちらも「私」の -ēn が共通で、来ると勉強するでは過去・現在・未来を作る部分が違います。現在形は習慣にも使います。今まさに進行中かどうかは時の表現や進行の構文まで見て判断します。

3．引用は、発言や考えをひとかたまりにする

-nnu は前の内容を「〜と」とまとめ、言う・思うなどにつなぎます。引用の中の主語と、言った人は必ずしも同じではありません。日本語でも「彼は『私は行く』と言った」の「私」が誰かを考えるのと同じです。

வருவேன் என்று சொன்னேன். varuvēn enṟu sonnēn
「私は来る」と言った。

enṟu は書き言葉で見かける引用形で、会話の -nnu と対応します。varuvēn は引用の中の未来、sonnēn は発言した過去。文全体を一つの時制にそろえる必要はありません。第8課では、この引用した内容を条件にします。

4．「試しにする」と「しようとする」

第1課の連結形＋pāru と、この課の不定形＋pāru は近い仲間ですが、接続が違います。動作をしてみて経験・結果を見る読みと、動作の実現を試みる読みを分けると、歌の勧めが立体的になります。

வாழ்ந்து பாரு / வாழ பாரு vāḻndhu pāru / vāḻa pāru
生きてみて／生きようとしてみて

前者は連結形、後者は不定形。実際の文脈では意味が近づくこともありますが、全く同じ形として覚えず「どの形で pāru に接続したか」を確認します。
