Lesson 4

எப்புடி இருந்த நாங்க

eppuḍi irundha nāṅga
エップディ・イルンダ・ナーング
「どうだった私たち」
→ あんなだった俺たちが、どうしてこうなった？
= how we were / how did we end up like this?
タミル語をタップすると読み上げます。
பாடகர்கள் pāḍagargaḷ： அந்தோணி தாசன் andhōṇi dāsan・ முத்துலிங்கம் muttuliṅgam・ விவேக் சிவா vivēk sivā
இசை அமைப்பாளர் isai amaippāḷar： விவேக் - மெர்வின் vivēk - mervin

この曲で掴む形

A｜எப்புடி eppuḍi / இப்புடி ippuḍi — 「どう／こう」の超口語
B｜ஆயிட்டோம் āyiṭṭōm / மாட்டிகிட்டோம் māṭṭikkiṭṭōm — 「〜になっちゃった／ハマっちゃった」
C｜முடியல muḍiyala / -வே -vē — 口語否定＋「〜さえ」
D｜விழுறோம் viḻuṟōm / விடுறோம் viḍuṟōm — 一人称複数の口語現在
E｜சிரிச்சா siriccā / அடிச்சா aḍiccā — 口語条件「〜したら」
F｜ஒத்துக்கோ ottukkō / கட்டிக்கோ kaṭṭikkō / பெத்துக்கோ pettukkō — 口語命令＋補助動詞
