இருந்த irundhaஇரு iru「いる・ある・〜である」→ 過去の名詞修飾形過去連体〜だった／〜していた
நாங்க nāṅgaநாங்கள் nāṅgaḷ の日常口語形一人称複数私たち／俺たち

எப்புடி eppuḍi は、標準寄りの எப்படி eppaḍi が会話で丸くなった形です。この曲ではさらに இப்புடி ippuḍi「こう／こんなふうに」も並びます。

எப்படி eppaḍi → どう
எப்புடி eppuḍi → 同じ意味の強い口語
இப்படி ippaḍi → こう／こんなふうに
இப்புடி ippuḍi → その強い口語
会話の軸：நாங்க nāṅga はこの曲の主語の中心です。ここから Lesson 1〜3 の「私／彼」中心から、私たちの活用へ広げます。なお நாம் nām は聞き手を含む「私たち」に使われることがあり、நாங்க nāṅga と完全な一対一ではありません。

「私たち」と活用の見取り図

歌詞へ入る前の足場です。先の課で見た形を、今回の曲に必要な理由から捉え直します。

1．「私たち」に相手を含むか

日本語では同じ「私たち」でも、タミル語は聞き手を含める形と含めない形を区別します。歌の nāṅga は口語の排他的な私たち。一般的な案内や誘いでは、誰を仲間に入れているかが大切です。

நாங்கள் / நாம்; நாங்க / நாம nāṅgaḷ / nām; nāṅga / nāma
聞き手を含めない私たち／聞き手を含む私たち；それぞれの口語形

書き言葉と会話形の対応です。「複数だから nāṅga」とだけ覚えると、一緒にやろうと相手を誘うときの違いを失います。ただし実際の会話では地域や場面による使い分けもあります。

2．語尾から人物を回収する

主語が省略されても、肯定の有限動詞は人称・数などの手掛かりを持ちます。まず規則が見えやすい書き言葉の「来た」を並べ、歌の口語形と比較しましょう。

வந்தேன் / வந்தாய் / வந்தான் / வந்தாள் / வந்தோம் / வந்தீர்கள் / வந்தார்கள் / வந்தது vandhēn / vandhāy / vandhān / vandhāḷ / vandhōm / vandhīrgaḷ / vandhārgaḷ / vandhadhu
私／君／彼／彼女／私たち／あなた・あなた方／彼ら・敬称の方／中性のものが来た

男女の違いはここでは三人称単数の区別です。「私が女性だから -āḷ」とはしません。敬称は人数だけの問題ではなく、一人にも複数系の形を使います。物を人と同じ語尾にしないことも大切です。

3．過去の作り方は、連結形にも戻ってくる

vandhu、paḍitthu のような連結形と、vandhēn、paḍitthēn のような過去形には共通部分が見えます。しかし、連結形そのものが常に「昔」を意味するわけではありません。

வந்து பாரு / படித்து பாரு vandhu pāru / paḍitthu pāru
来てみて／読んでみて・勉強してみて

どちらもこれからするよう勧められます。過去語幹と形が関係していても、命令を含む構文全体の時間は未来方向です。第1課の連結形を「過去形」と呼ばなかった理由が、ここでつながります。
