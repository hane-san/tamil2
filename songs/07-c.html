C｜雨の比喩で覚える：-ஆமல் -āmal / -ஆம -āma / -ஆதே -ādhē

கொட்டுற மழையா நீ வந்த
koṭṭuṟa maḻaiyā nī vandha
コットゥラ・マライヤー・ニー・ヴァンダ
「降り注ぐ雨のように、君は来た……」
→ 君は土砂降りの雨みたいにやって来た
= you came like pouring rain.
கொட்டுற koṭṭuṟa標準寄り கொட்டுகிற koṭṭugiṟa の口語名詞修飾降り注ぐ〜／pouring
மழையா maḻaiyāமழை maḻai「雨」＋様態 -ஆ -ā雨のように／雨として
வந்த vandhaவா vā「来る」過去名詞修飾来た〜。歌詞では文末的に圧縮
மண்ணுல ஏழையா நான் நெனச்சேன்
maṇṇula ēḻaiyā nān nenaccēn
マンヌラ・エーライヤー・ナーン・ネナッチェーン
「土／世界の中で、貧しい者として、私は思った」
→ この表記のままでは意味の接続が不自然
= the supplied wording is semantically uncertain.
表記保留：நெனச்சேன் nenaccēn 自体は நினைத்தேன் ninaitthēn「私は思った」の口語です。ただし雨の前後文脈との接続が不自然なので、似た音の別語が転記されている可能性もあります。原文は変更しません。
கேட்காமலே வந்த சொல்லாம மழை போல
kēṭkāmalē vandha sollāma maḻai pōla
ケートカーマレー・ヴァンダ・ソッラーマ・マライ・ポーラ
「尋ねずに来た、言わないで、雨のように」
→ 何も聞かず、何も告げずに突然来る雨みたいに
= like rain that comes without asking or saying a word.
கேட்காமலே kēṭkāmalēகேள் kēḷ「聞く・尋ねる」＋否定連結 -ஆமல் -āmal＋ -ஏ -ē聞かずに／尋ねもせずに
வந்த vandha過去名詞修飾来た〜
சொல்லாம sollāma標準寄り சொல்லாமல் sollāmal の口語言わずに／without saying
மழை போல maḻai pōla比較雨のように／like rain
சொல்லாமல் sollāmal → 標準寄り「言わずに」
சொல்லாம sollāma → 日常口語「言わずに」
Lesson 6: அடங்காம aḍangāma「おさまらず」も同じ縮約
நீ விட்டு போகாதே
nī viṭṭu pōgādhē
ニー・ヴィットゥ・ポーガーデー
「君、置いて行かないで」
→ 僕を置いて行かないで
= don't leave and go away.
விட்டு viṭṭuவிடு viḍu「放す・置く」連結形置いて／離して
போகாதே pōgādhēபோ pō「行く」＋否定命令行かないで／don't go
否定名詞修飾との違い：போகாத pōgādha なら「行かない〜」。போகாதே pōgādhē は相手への「行かないで！」です。最後の -ஏ -ē まで含めて否定命令として耳で覚えます。
இந்த ஏழை இங்க வாழாதே
indha ēḻai inga vāḻādhē
インダ・エーライ・インガ・ヴァーラーデー
「この哀れな者、ここで生きるな」
→ 表面形では否定命令だが、文脈上の主語関係は圧縮されている
= surface form: “don't live here”; the lyric syntax is compressed.
ஏழை ēḻai は「貧しい人／哀れな者」。ただし இந்த ஏழை indha ēḻai と வாழாதே vāḻādhē の主語対応は通常の会話文としては不自然です。歌詞特有の省略を前提に、否定命令の形だけ確実に拾います。
