C｜「種の中に木、言葉の中に意味」：-இனுள் -inuḷ と -ஆய் -āy

விதையினுள் விருச்சமாய்
vidhaiyinuḷ viruccamāy
ヴィダイイヌル・ヴィルッチャマーイ
「種の内側に、樹として」
→ 種の中に眠る大樹のように
= like a tree within a seed.
விதையினுள் vidhaiyinuḷவிதை vidhai「種」＋連結 -இன் -in＋ உள் uḷ「内側」種の中に
விருச்சமாய் viruccamāy提供表記。文脈上は「樹」を表す語＋文学的様態 -ஆய் -āy木として／大樹のように
綴り注意：விருச்சம் viruccam は提供歌詞の表記です。標準的には விருட்சம் viruṭcam などの表記も見られる語で、「樹・木」を意味します。教材では原文を変えず、意味だけ安全に拾います。
சொல்லினுள் பொருளாய்
sollinuḷ poruḷāy
ソッリヌル・ポルラーイ
「言葉の内側に、意味として」
→ 言葉の中に宿る意味のように
= like meaning within a word.
சொல்லினுள் sollinuḷசொல் sol「言葉」＋ -இன் -in＋ உள் uḷ言葉の中に
பொருளாய் poruḷāyபொருள் poruḷ「意味・物」＋文学的 -ஆய் -āy意味として／意味のように
மழலைக்குள் அமிழதமாய்
maḻalaikkuḷ amiḻadhamāy
マラライックル・アミラダマーイ
「幼い声／赤子の言葉の中に、甘露として」
→ 幼子の声の中に宿る甘露のように
= like nectar within a child's babble.
மழலைக்குள் maḻalaikkuḷமழலை maḻalai「幼子・幼い言葉」＋ உள் uḷ 系幼い声／幼子の中に
அமிழதமாய் amiḻadhamāy提供表記。文脈上は「甘露・不死の霊薬」系の語＋ -ஆய் -āy甘露として／nectar のように
表記保留：அமிழதமாய் amiḻadhamāy は標準形として切りにくく、文脈上は அமிழ்தம் amiḻdham / அமுதம் amudham「甘露・nectar」系に近いと考えられます。音源未確認なので原文を保持します。
கல்லினுள் சிலையாய்
kallinuḷ silaiyāy
カッリヌル・シライヤーイ
「石の内側に、像として」
→ 石の中に眠る彫像のように
= like a sculpture within stone.
கல்லினுள் kallinuḷகல் kal「石」＋ -இன் -in＋ உள் uḷ石の中に
சிலையாய் silaiyāyசிலை silai「像・彫像」＋ -ஆய் -āy彫像として／彫像のように
この連の型：「X の中に Y として」を四つ並べています。-இனுள் -inuḷ は「〜の内側に」、-ஆய் -āy は文学的な「〜として／〜のように」。日常会話なら உள்ளே uḷḷē「中に」、மாதிரி mādhiri「〜みたいに」の方が使いやすいです。
