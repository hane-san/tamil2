# 歌で学ぶタミル語

`tamil2` の本課・補講とは別に、好きな曲を読解しながら口語タミル語を定着させるレイヤーです。

## 役割

- 本課：文法体系を順序立てて理解する
- 補講：本課にない重要項目を補う
- 歌教材：実際の歌詞から、語彙・口語形・格・活用を逆向きに回収する

歌教材の進捗や表現は本課の正本データとは分離します。

## 表示ルール

各行は原則として次の順で扱います。

1. タミル文字
2. ローマ字
3. カナ
4. 日本語直訳
5. 日本語の自然な意味
6. 英語の直訳・構造対応
7. 単語・形の分解
8. 動詞や格の「現在地」
9. 口語形と標準寄りの形の対応
10. 日常会話へ転用できる例

解説中に出るタミル語にもローマ字を付けます。青いタミル語は `ta-IN` の端末TTSで読み上げます。

同じ行でタミル文字とローマ字を並べる場合は、必ず半角スペースを1つ入れて `தமிழ் romanisation` の形にします。CSS の余白だけには依存せず、HTML上でも両者の間に実際の半角スペースを残します。スマホで見出しが折り返す場合はローマ字を次行に落として構いません。

歌詞中の同一箇所が繰り返される場合は、初出で詳説し、反復部分は同じ語彙・文法を耳で再認識する区間として扱います。

## Lesson 1

- `01-vaazhndhu-paaru.html` — வாழ்ந்து பாரு / vāḻndhu pāru
- 主な項目：連結形、不定形、口語現在、非過去修飾、場所格、与格、目的格、-உம்、-ஆய்、-ஏ、口語⇄標準寄り
- 本文は `01-title.html`、`01-a.html`〜`01-d.html`、`01-summary.html` に分割。

## Lesson 2

- `02-marandhu-poche.html` — மறந்து போச்சே / maṟandhu pōccē
- 主な項目：結果・完了 `போச்சு pōccu`、口語否定 `-ல -la`、口語場所格、疑問 `-ஆ -ā`、否定連結 `-ஆமல் -āmal`、条件 `-னால் -nāl`、様態 `-ஆய் -āy`、使役 `V + வை vai`、`வேண்டும் vēṇḍum`、大きな口語縮約
- 本文は `02-title.html`、`02-a.html`〜`02-d.html`、`02-summary.html` に分割。
- 提供歌詞の綴りが文脈上の標準形とずれる箇所は勝手に置換せず、原文を残して注記する。

## Lesson 3

- `03-innum-ethana-kaalam.html` — இன்னும் எத்தனை காலம் / innum ettanai kālam
- 主な項目：数量疑問 `எத்தனை ettanai`、口語関係語 `கிட்ட kiṭṭa`、口語現在疑問 `-ுறியா -uṟiyā`、一人称未来 `-ப்பேன் -ppēn`、口語否定 `-ல -la`、口語引用 `-ன்னு -nnu`、口語条件 `-ச்சா -ccā`、`V + போது pōdhu`、比較 `போல pōla`、完了・結果 `பூத்திருச்சு pūttiruccu`、口語完了 `புரிஞ்சிகிட்டேன் purinjikkiṭṭēn`。
- Lesson 1 の `V + பாரு pāru`、Lesson 2 の `புரியல puriyala`・結果表現を再利用し、曲を跨いで同じ構造を反復する。
- 本文は `03-title.html`、`03-a.html`〜`03-d.html`、`03-summary.html` に分割。

## 追加方針

曲数を増やす際も、一曲を単なる翻訳にせず、既習文法の再登場と新しい文法の導入が見えるようにします。最終的には初級〜中級の主要項目が複数曲を通じて反復される構成を目指します。
