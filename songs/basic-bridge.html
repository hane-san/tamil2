歌から日常へ、初級補充ノート

第3〜10課の合間に、必要な項目へ戻って使ってください。

数・数量・時刻は、名詞と組み合わせる

数える形と名詞の前の形が違うことがあります。特に「一つ」の oṉṟu と「一つの〜」の oru を対にします。英語の a/an に近い働きになる場合もありますが、冠詞の規則をそのまま移すのではありません。

形・読み意味
ஒன்று / ஒரு புத்தகம் oṉṟu / oru putthagam一つ／一冊の本
இரண்டு / மூன்று / நான்கு / ஐந்து iraṇḍu / mūnṟu / nāngu / aindhu2／3／4／5
ஆறு / ஏழு / எட்டு / ஒன்பது / பத்து āṟu / ēḻu / eṭṭu / oṉbadhu / patthu6／7／8／9／10
இருபது / நூறு / ஆயிரம் irubadhu / nūṟu / āyiram20／100／1000
எத்தனை புத்தகங்கள்? / எவ்வளவு தண்ணீர்? etthanai putthagaṅgaḷ / evvaḷavu thaṇṇīr何冊の本？／どれだけの水？
மூன்று மணிக்கு / மூன்று மணி நேரம் mūnṟu maṇikku / mūnṟu maṇi nēram3時に／3時間

数えられる個数には etthanai、量には evvaḷavu が役立ちます。時点の「3時に」では与格、長さの「3時間」では時間量を表すまとまりを使います。iraṇḍu は会話で reṇḍu、oṉṟu は oṇṇu のような形にも出会います。まず数字を見て言い、次に買いたい物や待ち時間と組み合わせて練習します。

「私の本」と「私は本を持っている」

所有者が名詞を修飾する形と、持っていることを一文で述べる形を分けます。第6課で確かめた「名詞のまとまり」と「文」の違いです。

形・読み意味
என் புத்தகம் / உன் புத்தகம் en putthagam / un putthagam私の本／君の本
என்னிடம் ஒரு புத்தகம் இருக்கிறது。 enniḍam oru putthagam irukkiṟadhu私のところに本が一冊ある・私は本を一冊持っている
எனக்கு ஒரு தம்பி இருக்கிறான்。 enakku oru thambi irukkiṟān私には弟が一人いる

所有は英語の have 一語へ対応させず、「誰のところに何があるか」「誰にどんな関係があるか」の構文で捉えます。人と物で iru の語尾も違います。口語では kiṭṭa や irukku などに出会いますが、ここでは関係が見えやすい書き言葉寄りの形で示しています。

形容詞・副詞・比較を分ける

「よい本」は本を説明し、「よく読む」は読む動作を説明します。日本語と同じように、説明する相手が名詞か動作かを先に確かめます。

形・読み意味
நல்ல புத்தகம் / நன்றாகப் படி nalla putthagam / nanṟāgap paḍiよい本／よく勉強しなさい
இதை விட அது பெரியது。 idhai viḍa adhu periyadhuこれより、それの方が大きい
மிகவும் நல்லது migavum nalladhuとてもよい

比較の基準は「これ＋目的格」の idhai に viḍa を続けます。英語の than に似た関係を、基準の後ろで示すと考えると語順をつかめます。periyadhu は中性のものを「大きい」と述べる形で、人を述べる形へ機械的に流用しません。

理由と目的を、結果から区別する

理由は「なぜそうなったか」、目的は「何を実現しようとしたか」です。どちらも日本語では「〜ので・ため」に近づくため、語形だけでなく出来事の関係を見ます。

形・読み意味
மழை பெய்ததால் நான் வரவில்லை。 maḻai peydhadhāl nān varavillai雨が降ったので、私は来なかった
தமிழ் படிக்க வந்தேன்。 thamiḻ paḍikka vandhēnタミル語を勉強しに来た

peydhadhāl は「降ったこと」を原因として示す形です。単純な条件 peydhāl「降れば」とは異なります。後者は paḍikka という不定形で来た目的を示しています。第5課の条件、第6課の不定形へ戻って三つを並べると、訳語に頼りすぎずに読めます。

習慣・進行・結果を見分ける

現在形だけで「今まさに最中」とは限りません。毎日の習慣も現在形で表せます。進行を明示する構文では、連結形と補助動詞がまとまって働きます。

形・読み意味
நான் தினமும் படிக்கிறேன்。 nān dhinamum paḍikkiṟēn私は毎日勉強します
நான் இப்போது படித்துக்கொண்டிருக்கிறேன்。 nān ippōdhu paḍitthukkoṇḍirukkiṟēn私は今、勉強しているところです

二つ目は paḍitthu＋koṇḍu＋iru の系列で進行を表し、最後の -ēn が話者を示します。このような複合形にも、動作・その眺め方・人称という層があります。歌の強い縮約は、この丁寧な形から常に一対一で予測できるわけではありません。

五つの短い実践

本を2冊と言う／自分の持ち物を一つ説明する／二つの物の大きさを比べる／来られない理由を言う／毎日の習慣と今していることを言い分ける。まず上の例の名詞だけを替え、次に解説を見ずに文を作ります。
